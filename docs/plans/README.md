# Plans (internal)

This folder holds design notes and implementation plans from Ghost's development, kept public for
transparency. It is a working record, not user documentation: entries are
written for the maintainers at the time, are not updated afterwards, and may
describe behaviour that has since changed. Paths in logs are normalised to
`<repo>` and `<user>`.

For how Ghost works today, start at the [documentation index](../README.md);
for what shipped in each release, see the [CHANGELOG](../../CHANGELOG.md).
